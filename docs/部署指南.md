# GlassBlog 部署指南

> 目标：本地写文章 → `发布.bat` 一键推送 → Vercel 自动构建 → 全世界可访问。
> 全程零服务器成本（GitHub + Vercel 免费档足够个人博客商用）。

---

## 0. 前置条件

| 工具 | 用途 | 检查方式 |
| --- | --- | --- |
| Node.js ≥ 18 | 跑博客 | `node -v` |
| Git | 推送代码 | `git --version` |
| GitHub 账号 | 托管源码 | [github.com](https://github.com) 注册 |
| Vercel 账号 | 部署托管 | [vercel.com](https://vercel.com) 用 GitHub 登录 |

## 1. 第一次部署（五步）

### ① 配置 git 身份（只需一次）

```bash
git config --global user.name "你的GitHub用户名"
git config --global user.email "你GitHub绑定的邮箱"
```

### ② 在 GitHub 建一个私有仓库

GitHub → New repository → 名字随意（如 `glassblog`）→ **Private** → 不要勾选任何初始化选项。

### ③ 关联远程并推送

在本项目根目录打开终端：

```bash
git remote add origin https://github.com/你的用户名/glassblog.git
node scripts/publish.mjs
```

> 推送时 GitHub 会要求登录，按提示在浏览器授权即可。
> 如果报错 `push declined due to repository rule` 或超时，可改用 SSH 方式（见第 4 节排错）。

### ④ Vercel 导入项目

1. [vercel.com](https://vercel.com) → 用 GitHub 登录 → Add New → Project
2. Import 刚才的 `glassblog` 仓库
3. Framework Preset 会自动识别 **Next.js**，不用改任何配置
4. **展开 Environment Variables，添加一条**：
   - Key：`ADMIN_MODE`
   - Value：`cloud`
   - **这一步必做**：它会让线上的 `/admin` 和所有写接口直接 404，别人无法碰你的后台
5. 点 Deploy，等 1-2 分钟构建完成

### ⑤ 访问你的博客

Vercel 会分配一个 `xxx.vercel.app` 域名，直接可访问。以后：

- 本地双击 `写作.bat` 写文章、传图、调设置
- 写完双击 `发布.bat`，约 1-2 分钟后线上自动更新

## 2. 绑定自己的域名（可选，商用建议）

1. 在阿里云/腾讯云买好域名并**完成实名认证**
2. Vercel 项目 → Settings → Domains → 输入域名 → Add
3. 按提示到域名控制台加解析记录：
   - A 记录：`@` → `76.76.21.21`
   - CNAME 记录：`www` → `cname.vercel-dns.com`
4. 回到 Vercel 点 Refresh，等状态变绿
5. 把 `config/site.json` 的 `siteUrl` 改成 `https://你的域名`，再 `发布.bat` 推一次——sitemap/RSS/分享卡片就会用正式域名

> 国内访问 Vercel 默认域名偶尔较慢，绑定自有域名 + 开启 CDN 会明显改善；若商用对速度要求高，可在域名服务商处配置国内 CDN 加速。

## 3. 日常写作流程

```
双击 写作.bat → 浏览器自动打开后台
  ├─ 写文章（可存草稿反复改）
  ├─ 传图片（自动压缩成 webp）
  ├─ 发说说 / 改设置
  └─ 满意后 → 双击 发布.bat → 上线
```

## 4. 排错速查

| 症状 | 原因与解法 |
| --- | --- |
| `写作.bat` 闪退 | 右键"在终端中打开"手动运行看报错；多半是没装 Node |
| 推送被拒 `non-fast-forward` | 线上有别人的提交？执行 `git pull --rebase origin main` 后再发布 |
| 推送报 `Connection was reset / Could not connect` | 直连 GitHub 被重置。发布脚本会自动改走本机系统代理（127.0.0.1:11129）重试；若代理客户端没开会继续失败，把代理开起来再发 |
| HTTPS 推送反复失败/超时 | 换 SSH：`git remote set-url origin git@github.com:用户名/仓库名.git`，SSH key 配置见 GitHub 文档 |
| 线上文章没更新 | Vercel 控制台看 Deployments 是否构建成功；失败多半是某篇文章 YAML 头格式错误 |
| 线上能打开 `/admin` | 检查 Vercel 环境变量 `ADMIN_MODE=cloud` 是否配了，配了要 Redeploy 一次 |
| 图片上传失败 | 图片需 ≤10MB；`public/uploads` 目录有写入权限 |

## 5. 安全清单（商用前过一遍）

- [ ] Vercel 环境变量已设 `ADMIN_MODE=cloud`
- [ ] `config/secrets.local.json` 没有出现在 git 里（`.gitignore` 已兜底，`git status` 确认）
- [ ] 后台密码已从默认 `glassblog` 改掉
- [ ] `site.json` 里 ICP 备案号已填（国内商用合规）
- [ ] AI API key 只存在本地 secrets，从未写进文章或配置截图
