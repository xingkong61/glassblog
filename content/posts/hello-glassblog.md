博客正式开张了。整个站点是一块会呼吸的毛玻璃：卡片半透明、背景光斑缓慢漂浮、深色模式下变成一片安静的深蓝。

## 为什么是毛玻璃

不是跟风。写博客这件事，内容是主角，界面越"轻"，文字越"重"。毛玻璃的好处恰好是：

1. 背景被虚化，视线自然聚焦到内容上
2. 卡片之间有真实的层次感，像摞起来的磨砂玻璃板
3. 配上一点点彩色光斑，页面就有了"活着"的感觉

> 界面是玻璃，内容才是光。

## 这个站怎么搭的

技术栈很简单：Next.js + Tailwind CSS，内容就是一堆 Markdown 文件。写文章走本地后台，点一下发布就推到线上。

```js
// 整个博客的哲学
const blog = markdown + glass;
```

后续会写几篇建站手记，把踩过的坑都摊开讲。
