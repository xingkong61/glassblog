写博客不需要精通 Markdown，这一页就够。

## 基础三件套

- **标题**：`##` 起手，一个 `#` 是文章大标题，正文里从 `##` 用起
- **列表**：`-` 无序，`1.` 有序
- **强调**：`**加粗**`、`*斜体*`、`~~删除线~~`

## 引用与代码

> 引用适合放金句、注释和"划重点"。

行内代码像这样：`npm run dev`。代码块带上语言名就有高亮：

```python
def hello(name: str) -> str:
    return f"你好, {name}!"
```

## 表格

| 快捷键 | 作用 |
| --- | --- |
| Ctrl+B | 加粗 |
| Ctrl+K | 插入链接 |
